# データソース

「日本人の健診の数値はどこで違っているか」。第1版は公開の集計 Excel だけを使う。レセプト情報・特定健診情報の第三者提供（個票）には入らない。

## 1. 結論

厚生労働省「NDBオープンデータ」第11回（2026-06-16 公開）の特定健診。年度は **2023年度（令和5年度）**。同じ回のレセプトは令和6年度で、年が1つ新しい。

ページ: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000177221_00017.html

ZIP: `https://www.mhlw.go.jp/content/12400000/001711940.zip`（特定健診 検査）

読むブックは1つ。

`07_特定健診_検査項目/各項目の平均値　都道府県別性年齢階級別分布.xlsx`

ファイル名の区切りは全角空白。シートは `各項目の平均値`。見出しは「特定健診 平均値：2023年度」。

## 2. 軸

行は都道府県（北海道から沖縄県、その後に `都道府県判別不可` と `全国`）× 検査項目。都道府県の列はブロックの先頭行だけ埋まっている。

列は男・女 × 5歳階級（40–44 … 70–74）× 各性の中計。各セルは平均。

検査項目は BMI、腹囲、空腹時血糖、HbA1C、収縮期血圧、拡張期血圧、中性脂肪、HDL、LDL、GOT、GPT、γ-GTP、ヘモグロビン、随時血糖、血清クレアチニン、eGFR。ブック上の HDL・LDL・GOT・GPT・γ-GTP は全角。

男の平均と女の平均は人数が無いので足し合わせない。地図の既定は男の中計。分母は同じ項目・性・年齢の全国行。`都道府県判別不可` は升目にしない。

## 3. cube

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `public/data/geo.json` | item × sex × age × area | mean, relative | items, sexes, ages, areas |
| `public/data/age.json` | 同じ | mean | 同じ |

`relative` = そのセルの平均 / 同じ item・sex・age の全国平均。全国行自身は地図に塗らない。欠測は `null`。

平均は小数4桁、比は小数4桁。色の尺度は項目をまたいで固定し、1/1.15〜1.15。特定健診の平均は全国の近くに寄る。1.5 まで広げると、県の差が紙色に溶ける。

## 4. 欠測

この平均値ブックの見出しに、分布表の「10未満は『‐』」という注記は無い。数値はそのまま読む。

`都道府県判別不可` のヘモグロビンに、平均としてあり得ない `0` が数セルある。0 は欠測にして埋め戻さない。47都道府県と全国の平均に 0 は無い。

## 5. 第1版で読まないもの

二次医療圏別、`詳細情報レコード含む/`、分布ブック、質問票 ZIP（`001711941.zip`）。質問票は生活習慣の別問いなので、入れるなら後から第3ビューにする。年次（第1–11回）とレセプト指標もここには混ぜない。
